# Python Functions Practice

This assignment practices defining functions and calling them from another Python file.

## Files
- `a6_function_smorgasbord.py` — the main program to run.
- `a6_my_functions.py` — functions imported by the main program.

Both files are required, so keep them in the same folder with their original filenames.

## Run
Open a terminal in this folder and enter:

python a6_function_smorgasbord.py

Requires Python 3. No additional packages are needed.
